# Генератор фрактального пламени (Fractal Flame)

## 📌 Описание проекта
Высокопроизводительное приложение на Python для генерации детализированных изображений фрактального пламени на основе алгоритма Chaos Game и нелинейных вариаций.

## 🛠 Технологии и реализация
* **Язык:** Python
* **Реализация:** Однопоточный и многопоточный рендеринг, поддержка аффинных преобразований и математических функций (swirl, horseshoe и др.).
* **Что использовано:** Модуль `multiprocessing` для параллельных вычислений (CPU-bound задача), математические вычисления с плавающей точкой, генерация PNG-изображений.
* **Изученные инструменты:**
  * Параллельное программирование и многопроцессность в Python.
  * Оптимизация производительности тяжелых вычислительных задач.
  * Модульное и бенчмарк-тестирование (`pytest`).

## 🚀 Инструкция по запуску
1. Установите зависимости:
   ```bash
   poetry install
   ```
2. Запуск генерации:
   ```bash
   python main.py --seed 42 -i 5000 -t 4
   ```
3. Запуск тестов:
   ```bash
   pytest
   ```
